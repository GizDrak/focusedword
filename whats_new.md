# What's New in Focused Word

## v0.8.5 — Major Update

Welcome to the biggest update yet! This release brings notes, split-screen reading, smarter sync, and a whole lot more.

### ✍️ Notes
Take rich, organized Bible study notes right inside the app.
- Full WYSIWYG editor — bold, italic, headings, lists, blockquotes, superscript, and more.
- **Color-coded categories** keep your notes organized at a glance.
- **Auto-save** — your notes save as you type. No save button needed.
- **Auto-tagging** — type `#topic` in your note and it becomes a searchable tag. Tap any tag to find related notes, bookmarks, and highlights.
- Sort by date or title; filter by category. Swipe to delete from the list.
- Notes sync across all your devices.

### 📖 Split Mode (Tablet & PC)
Compare two translations side-by-side.
- Both panels stay on the same chapter and verse, synchronized.
- Tap a verse in either panel to highlight it in both.
- Pick a different translation for each panel — your choice is remembered next time.
- Available on screens 768px and wider. Find it in the Mode menu.

### 🔄 Sync, Rebuilt
Sync is faster and more reliable than ever.
- Rewritten for a new server API with smarter conflict resolution.
- Notes, categories, and metadata all sync with correct timestamps.
- Sync now uses a single request, cutting network traffic in half.
- Bookmark sets now sync across devices too.
- Added a "Change Server" option in the sync setup.

### 🏷️ Tags for Bookmarks & Highlights
- Add tags to any bookmark or highlight — type `#tag` and press Enter.
- Tap a tag chip to search across everything.
- Tags persist across sessions and sync to your other devices.

### 📚 Library, Refreshed
- Notes tab now matches the clean layout of bookmarks and highlights — color stripe, swipe-to-delete with undo, and tappable tag chips.
- Cleaner filter dropdowns for bookmark sets and note categories.
- Manage bookmark sets with a new popover — rename or delete any set with one tap.

### 🧭 Navigation Improvements
- **Old/New Testament tabs** in the book list jump you to the right section fast.
- **Breadcrumb navigation** (Books › Book › Chapter › Verse) makes it easy to back out.

### 🎯 Reading Mode Polish
- **Spotlight mode** got a smoother custom scroll animation.
- **Hold-to-advance** — press and hold a touch zone to auto-advance verses.
- Paragraph mode now works beautifully in Spotlight.
- Split mode uses spotlight navigation so both panels move verse-by-verse.
- Spacebar no longer conflicts with the notes editor — use arrow keys instead.

### 🎨 Themes & Icons
- The app icon now adapts to your theme — a light variant on light themes, a dark variant on dark themes.
- Landscape and tablet use are now fully supported (portrait lock removed).

### 🔧 Under the Hood
- All app data migrated into a single unified database for better reliability.
- Tag browser loads instantly with a cached tag index.
- Many stability fixes across sync, rendering, and navigation.
